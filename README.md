# Kom igång med Git

I det här repot får du öva på grundläggande Git-kommandon. Du arbetar med din egen kopia av klassens GitHub-template. Ändringar du skickar upp påverkar alltså ditt repo på GitHub.

## Målet

Du ska öva på att klona ett repo, granska och spara ändringar, arbeta i en branch och synkronisera med GitHub. Arbeta uppifrån och ned i `OVNINGAR.md`.

## Innan du börjar

Du behöver Git installerat på datorn och ett GitHub-konto. På GitHub skapar du först din kopia av lärarens template med **Use this template**. Välj ett namn till ditt repo och skapa det på ditt konto.

Öppna sedan terminalen och klona URL:en till **ditt eget repo**:

```text
git clone <URL-till-ditt-repo>
cd <mappnamnet>
```

Ersätt texten inom vinkelparenteser med dina värden. Kör kommandona i terminalen, från mappen för repot.

Om Git ber dig ställa in namn och e-postadress gör du det enligt lärarens instruktioner. Använd gärna samma e-postadress som är kopplad till ditt GitHub-konto.

## Filer i övningen

- `OVNINGAR.md` innehåller steg och kontrollfrågor.
- `elevprofil.md` är din startfil för den första ändringen.
- `klassens-info.md` används för att öva på att hämta en ändring från GitHub.
- `mitt-forslag.md` redigerar du på din övningsbranch.

Ta en övning i taget och läs kontrollfrågorna. Innan du sparar en ändring, titta på vad `git diff` visar.
